# Canary Persona — 연구 번들

> 퍼소나/안전 연구 산출물 모음. **다른 리포로 통째로 이식할 수 있도록** 묶은
> 디렉터리입니다. 이 폴더 하나를 복사하면 연구의 개념·방법론·데이터셋 조사가
> 모두 따라옵니다.

## 1. 무엇이 들어 있나

문서는 **개념 → 데이터 → 방법론** 순서로 읽으면 됩니다.

| 파일 | 내용 | 역할 |
|------|------|------|
| `research-proposal.md` | **The Canary Persona** 연구 제안서 — 퍼소나를 계측기로 재정의, 카나리아 행동을 위반의 조기 신호로 | 최상위 비전 |
| `dataset-candidates.md` | 퍼소나 드리프트·제약 위반·장기기억 관련 후보 데이터셋·벤치마크 조사 | 데이터 기반 |
| `persona-collapse-protocol.md` | 탐지 장치 — PDS 메트릭, 상태 그래프, 사이클 탐지, lead time 정의 | 실험 방법론 |

세 문서는 서로를 **같은 디렉터리 기준 상대 경로**로 참조하므로, 폴더째 옮기면
내부 링크가 그대로 유지됩니다.

## 2. 이식 안내 (portability)

이 번들은 원래 `baryonlabs/experiential-memory-dataset` 리포에서 작성되었고,
아래 **원본 리포 자산**을 참조합니다. 새 리포에는 이 자산들이 없으므로, 이식 시
함께 가져오거나 새로 만들어야 합니다.

| 참조 경로 | 정체 | 새 리포에서 할 일 |
|-----------|------|--------------------|
| `soul-spec-anonymized/` | Agent B의 Soul Spec (`SOUL.md`, `IDENTITY.md`) | P0–P4 퍼소나 설계의 출발점 — 복사 권장 |
| `taskset.md` | 도메인 과업셋 (Category 4 = Context-Dependent Decisions) | 위반 시나리오 원형 — 복사 또는 재작성 |
| `evaluation/protocol.md` | 블라인드 평가 프로토콜 (조건 A/B/C/D) | 평가 절차의 베이스 — 복사 권장 |
| GitHub 이슈 #1, #2 | 원본 가설·기존 실험 데이터 | 새 리포 이슈로 옮기거나 링크로 보존 |

문서 본문의 위 경로 참조는 **원본 리포 기준**으로 남겨 두었습니다. 새 리포 구조가
정해지면 해당 경로만 일괄 수정하면 됩니다.

## 3. 연구 방향 (확정)

**퍼소나/안전 연구를 계속 진행합니다.** 핵심 줄기:

- 퍼소나를 *통제 대상*이 아니라 **계측기**로 다룬다.
- 일부러 특징적으로 설계한 퍼소나에 **카나리아 행동**을 심는다.
- 카나리아 소멸 → PDS 하락 → 상태 그래프 사이클 → 제약 위반 의 선행 관계를 검증한다.
